# Features

## Public Platform
- SEO-ready jobs and educations listing/detail pages.
- Editorial resources and informational pages.
- Dynamic legal pages with locale-aware routing.

## Authentication and Accounts
- Unified OTP-based access flow for register/login.
- Role-aware post-login routing.
- Password reset flow with template-driven email.

## Worker Features
- Structured profile and CV data management.
- Application history (jobs + educations).
- Privacy and consent controls.

## Employer Features
- Job CRUD and publication workflow.
- Application pipeline with status updates and notes.
- Employer profile and operational settings.

## Admin Features
- Jobs, employers, workers, applications moderation.
- Email templates and email send logs.
- Translation manager with nested key support.
- Notification preferences/digests management.
- Failed jobs retry/flush and system health diagnostics.
- Audit logs for operational accountability.
- Bugs section and error logs section.

## Bug Reporting and Diagnostics (Beta)
- Frontend "Report a bug" trigger and submission panel.
- Stores description, URI, optional screenshot, and 20-minute error snapshot.
- Notifies superadmins by mail for every new bug report.

## Localization
- EN/HR-first localized UI.
- Template-driven localized transactional emails.
- Admin-managed translation overrides.

## Ops and Reliability
- Queue-based notifications/mail.
- Health checks and failed jobs tooling.
- Retention/GDPR support primitives.
