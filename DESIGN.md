# CroWork Design System v4
## Cinematic Editorial Product Platform

---

# Brand Philosophy

CroWork is not a job board.

CroWork is:
- a relocation platform
- a future-building platform
- a premium European work product
- a cinematic editorial experience
- a calm optimistic digital environment

The emotional direction is:
- opportunity
- movement
- optimism
- future
- trust
- elegance
- confidence

The platform should feel like:
“a beautifully designed product helping people build a future in Croatia.”

---

# Visual DNA

The frontend must feel inspired by:
- Apple.com
- Linear
- Intercom
- Notion marketing
- Stripe editorial storytelling
- modern European product companies

NOT:
- HR software
- admin templates
- generic Tailwind SaaS
- crowded dashboards
- colorful startup kits

---

# Typography

## Primary Font — Geist

Use Geist everywhere for:
- UI
- body
- cards
- forms
- dashboards
- navigation
- tables
- settings
- chips
- metadata

Characteristics:
- clean
- highly readable
- premium
- modern
- restrained

---

## Display Font — Monument Extended

Use Monument Extended ONLY for:
- hero headlines
- cinematic section titles
- onboarding moments
- CTA banners
- editorial statements
- Coming Soon page

NEVER use it inside:
- forms
- dashboards
- tables
- dense UI
- navigation
- cards

Monument Extended exists only for emotional impact.

# Gradient System

IMPORTANT:
Gradients are NOT backgrounds.

Gradients are:
- atmosphere
- cinematic lighting
- emotional depth
- directional focus

Use:
- oversized blurred radial gradients
- subtle lighting blooms
- atmospheric edge glows

Avoid:
- rainbow gradients
- mesh overload
- neon
- hard transitions
- colorful sections

---

# Surface System

Depth comes from:
- composition
- spacing
- layering
- contrast

NOT:
- giant shadows
- glow effects
- glassmorphism overload

---

## Cards

All cards must:
- use white surfaces
- have subtle borders
- minimal shadows
- restrained radii

Card radius:
12px–16px

Mockup cards:
16px

CTA cards:
20px–24px

---

# Motion System

Motion should feel:
- cinematic
- expensive
- subtle
- restrained

Allowed:
- soft fades
- atmospheric drift
- hover lift
- smooth transitions
- elegant reveals

Forbidden:
- bounce
- elastic movement
- flashy motion
- aggressive scale

All motion must:
- remain performant
- remain GPU-friendly
- respect reduced motion

---

# Layout Philosophy

Every page must feel:
- art directed
- editorial
- spacious
- intentional
- calm

No page should feel:
- assembled
- template-based
- crowded
- dashboard-first

# CSS Architecture Rules

You MUST:
- audit all CSS
- remove dead code
- remove duplicate utilities
- normalize spacing
- normalize typography
- normalize radii
- normalize cards
- normalize motion
- normalize gradients

The system must become:
- scalable
- maintainable
- coherent
- premium

Avoid:
- utility chaos
- random one-off classes
- conflicting spacing systems
- conflicting card systems
- conflicting typography systems
